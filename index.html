            正在產出…
            有新版本可用

            45 秒：匯出 → 上傳 → 產出

            1. 匯出

            手機 Google 地圖 → 頭像 → 設定 → 位置和隱私 → 匯出檔案

            2. 上傳

            把 Timeline.json / GPX / KML 拖放到這個網頁（不上傳伺服器）

            3. 選段

            選月份或日期，也可按「今年行程」「最近旅程」

            4. 產出

            同意載入地圖後按「產出 MP4」，完成即可下載或分享

            只找到原始定位資料

            這個檔案有原始定位，但沒有已整理的到訪或行程。可以繼續，路線可能雜訊較多或不完整，距離也只是估計。

            建議先到 Google 地圖確認或還原時間軸，確認到訪與行程出現後再重新匯出，然後載入新檔。
